# 숨은 비밀: 새벽 단골 (운영자용)

> 플레이어에게 알리지 않는 이스터에그. README · 플레이어 안내에는 적지 않음.
> 코드: `economy/src/main/java/dev/stsv/economy/secret/dawn/` (`DawnRegular` · `DawnStory`), 설정: `contents/economy/secrets/dawn.yml`,
> 가게 쪽 연결: `store/StoreVisit.java` (다른 모듈이 편의점에 손님을 보내는 문), `store/StoreDay.java` (30초마다 물어봄 · 파라솔 · 그림자).
> 관리자 이름: `새벽단골` (id `dawn`). 서버에서 처음 푼 한 사람만 끝냄 (익명 공지 한 줄). **기념비 비석은 없음** (새로 온 사람이 열세 번째로 남도록, `Secret.hasStone()`).

## 이야기

이 가게의 첫 야간 알바였던 아저씨. 퇴근하는 새벽마다 바나나우유 하나를 사서, 파라솔 탁자에서 기다리던 어린 딸에게 건넸다.
어느 날부터 오지 못했다. 지금도 새벽이면 들어와 같은 것 하나를 사고, 파라솔 탁자에 빨대를 꽂아 둔 채 사라진다. 아무도 마시지 않는다.
네 번째 날 그는 병을 계산대에 두고 "곧 올 사람한테 건네 달라" 한다. 곧 밤샘 근무를 마친 간호사가 들어온다 — 오늘이 아빠 기일이라
새벽에 한번 와 보고 싶었던 그 딸. 바나나우유를 건네면 그녀는 단번에 알아보고, 창밖 파라솔에 그가 잠깐 앉아 고개를 끄덕이고 사라진다.

## 조건과 흐름

| 단계 | 무엇 | 넘어가는 조건 |
|---|---|---|
| 0 | 시작 전 | **야간 근무** (아래) 중, 게임 시각 **03~05시**, 밤에 받은 손님 평생 **150명 이상** (`start.night-served`), 30초마다 `start.chance` (0.25) |
| 1~3 | 새벽 손님 (스킨 `economy:entity/bus/night_regular`, 이름표 "새벽 손님", 버스 종류 `worker` 의 몸집) 이 바나나우유 하나를 사 감. 동전으로 딱 맞게 냄 (거스름돈 없음). 나간 뒤 파라솔 탁자에 병이 1분 놓임, 근무자에게만 한 줄 (`visits.<n>.after`) | 정상 계산 → 다음 단계. **하루(한국 시각)에 한 번**, 야간 근무의 03~05시에 30초마다 `visit-chance` (0.5) |
| 4 | 같은 사람, "곧 올 사람한테 건네줄래요?" 계산 뒤 **병이 계산대에 남음** | 계산 → 5 |
| 5 | 30초 안쯤 간호사 (`daughter`, 버스 종류 `nurse`) 가 빈손으로 계산대에 옴. 버튼 [바나나우유 건네기] · [어서 오세요] | **건네기** = 대사 4줄 → 파라솔에 그가 잠깐 (끄덕임) → 끝 (칭호). **인사** = 그냥 나감, 단계 4로 (다음 새벽에 다시). 그 사이 근무가 끝나면 (병이 사라짐) 역시 단계 4로 |

- 자리 (`StoreLayout`): 파라솔의 병 · 마지막의 그는 **왼쪽 파라솔 탁자** (`PARASOL_*` (-4.5, 0.78, 1.5) · `FIGURE_*` (-4.5, 2.3)): 계산 자리에서 온수기 왼쪽으로
  통유리 너머에 보임 (오른쪽 탁자는 온수기에 가려서 옮김). 그가 나타나는 순간 가게 안의 근무자 시선이 그쪽으로 한 번 돌아감. 계산대에 남는 병은 손님 화면 기둥 옆 (`PROP_*`).
- 야간 근무: 밤 20~06시에 출근했거나, 낮에 출근해 근무하다 20시를 넘긴 근무 (알바 이상: 그때 야간 조끼로 바뀜).
- 손님은 평범한 손님처럼 줄을 서고 기다려도 화내고 나가지 않음 (참을성 없음), 진상 · 신분증 · 장면에 끼지 않음, 인물 도감에 세지 않음.
- 보수는 평범한 손님 한 명 몫 (근무자의 경력 · 밤 손님 수에도 셈).
- 보상 (`rewards`): 칭호 **[새벽 단골]** (`economy:dawn_regular`, 숨은 칭호), 바나나우유 하나. 돈 없음.

## 확인 (테스트 모드)

1. `/관리자 비밀 테스트 켜기` → 시각 · 확률 · 밤 손님 수 · 야간 근무 조건 · 하루 한 번이 모두 풀림 (테스트 "하루" = `test-day-seconds`).
2. 편의점에서 근무 (`/관리자 편의점 시험` 도 됨) → 30초 안에 새벽 손님이 들어옴 → 계산. 다음 방문은 테스트 하루 (기본 60초) 뒤.
3. 빨리 보려면 `/관리자 비밀 단계 새벽단골 <나> 4` → 30초 안에 네 번째 방문 → 계산 → 곧 간호사 → [바나나우유 건네기].
   `단계 … 5` 는 계산대에 병이 있는 상태로 만들어 줌 (그 근무 동안만).
4. `/관리자 비밀 상태 <플레이어>` = 단계 · 밤 손님 수 · 마지막 방문 날 · 병이 계산대에 있는지. `/관리자 비밀 연출 새벽단골 그림자` = 확인 방법 안내.
5. 끝나면 `/관리자 비밀 초기화 새벽단골 <나>` · `테스트 끄기`.

## 저장

`eco.kv` 의 `secret.dawn.<uuid>.stage` · `since` · `day` (마지막으로 온 날). 계산대 위 병 (단계 5) 은 메모리에만 (근무가 끝나면 사라지고 단계 4로).
밤 손님 수는 편의점 경력 테이블 `eco_store_career.night`.
