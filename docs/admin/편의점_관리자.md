# GS26 편의점 — 관리자 안내 (경제 3.129.0)

플레이어용 설명은 `economy/README.md` "편의점", 기획은 `docs/plans/편의점_기획안.md`, 설정은 `contents/economy/store.yml` · `store_scenes.yml` · `items/store.yml` · `items/store_extra.yml`.
숨은 비밀 "새벽 단골"은 `docs/admin/숨은_비밀/새벽단골.md` (플레이어에게 알리지 않음).

## 1. 처음 세우기

1. 가게 앞에 설 자리에서 가게가 들어설 쪽을 보고 `/관리자 편의점 건설 마을점` (17×17, 틱마다 나눠 지음, 되돌리기 파일 남김). 이름마다 한 곳, 여러 곳 가능.
2. 다 지어지면 확인: 계산대 위 물건 · 버튼 · 금액 화면 · 카드 단말기 자리, 진열대 · 냉장고 방향, 간판, 발주 단말기 (계산대 끝), 뒷벽 차단기 (레버).
   **좌표를 손으로 계산한 곳이라 첫 건설 때 눈으로 꼭 확인.** 어긋나면 알려 주면 고침.
3. 가까이 (24칸 안) 버스 정류장이 있으면 버스 연동이 켜짐.
4. 예전 버전으로 지은 가게는 같은 자리에서 `건설` 을 다시 하면 발주 단말기 · 차단기가 생김.
5. 허물기: `/관리자 편의점 철거 <이름>` (땅 되돌림). 목록: `목록`.

## 2. 근무 흐름 (플레이어)

| 순서 | 무엇 |
|---|---|
| 출근 | 계산대 뒤 옷걸이 우클릭 → 조끼(경력 · 밤에 따라 기본 / 야간 / 점장) + 스캐너 |
| 손님 | 버스 동네 사람들 (37종) 이 시간대에 맞게 들어옴, 안에 최대 6명 (내 가게는 등급별 2/4/6) |
| 계산 | 물건을 바라보고 스캐너 우클릭 = 삑 (선임 · 점장대리 2개, 점장 3개 한 번에, 단골 바구니는 한 번에) → 카드 = 단말기, 현금 = 거스름돈 버튼 + [건네기] (거슬러 줄 금액이 크게 보임) |
| 잡일 | 배송 상자 (손에 안고) → 진열대 (상자를 바닥에 열고 물건이 하나씩 선반으로), 데우기 (문 · 불 · 띵 · 김, 오래 두면 연기), 폐기 (빨간 테두리 → 봉지 → 바구니), 쏟은 음료 (대걸레 3번 · 미끄럼 주의 간판), 컵 (쟁반 → 바구니), 온수기 (물통으로 부음, 물 높이 보임) |
| 응대 | 진상 12종 · 신분증 · 단골 "늘 먹던 걸로" · "다음 버스 언제 와요?" → 손님 위 초록 버튼 |
| 퇴근 | 옷걸이 다시 우클릭 → 평점 보너스 + 영수증. 3분 가만히 · 가게에서 30초 떠남 · 접속 끊김 · 죽음 · 서버 재시작 = 자동 퇴근 (번 것 그대로) |

## 3. 돈

- **손님을 보낼 때마다 바로 입금**: 기본 450 + 팁 (기분 90↑ 250 · 70↑ 150 · 40↑ 50, 손님 종류 팁 배수, 최대 2배) + 정확도 60.
- 퇴근 때 평점 보너스 (★4.5↑ +15% · ★4↑ +10% · ★3↑ +5%).
- 거스름돈을 더 준 것 (1원당 0.1 G) · 벌금은 다음 보수에서 뺌 (이미 준 돈은 안 가져감).
- 몫: 직영점 알바 40% (≈ 시간당 2만 G, 렌트 버스와 같음) · 내 가게 100% · 남의 가게 알바 40% + 점주 20% (점주가 접속 안 해도 바로 입금).
- 야간 근무 손님 ×1.3. 러시 (게임 7~9시 · 16~18시) 150초 안에 8명 = +1500 G. 정전 복구 +200 G. 본사 점검 70점↑ +1500 G / 40점↓ 벌금 800 G.
- 발주 적중: 하루 처음 +600 G, 그 묶음 물건 하나 팔 때마다 +60 G (빗나가도 +15 G, 잃는 돈 없음).
- 2인 근무의 진열 담당: 진열 600 · 잡일 250 · 손님 100 (몫 적용 전).
- 플레이어는 편의점에서 물건을 사지 않음 (손님은 NPC 만, 무인 계산대 없음). 근무 중이 아닌 사람이 진열대 · 계산대 · 온수기 등을 누르면 "직원만 쓸 수 있어요." 한 줄뿐.
  근무자가 받는 음식은 할머니의 사탕 (`store.yml gifts`) · 폐기 삼각김밥 (`waste.food`) 만.

## 4. 내 가게 (권리증)

| 등급 | 값 | 손님 | 상품 | 시간당 (100%) |
|---|---|---|---|---|
| 골목점 | 500,000 | 2 | 12 | ≈ 4.6만 |
| 표준점 | 1,500,000 | 4 | 22 | ≈ 8.1만 |
| 대형점 | 3,000,000 | 6 | 33 (술 · 담배 · 즉석 조리, 2인 근무) | ≈ 12만 |

- 상점 탈것 칸 (버스 바로 뒤) 에서 권리증을 삼. **내 땅** 17×17 안에서 같은 자리를 두 번 우클릭 = 지음 (한 사람 한 가게).
- 더 큰 권리증 = 예전 등급 값을 돌려주고 다시 지음 (차액만 낸 셈). 옷걸이를 웅크리고 두 번 우클릭 = 허물고 권리증 돌려받음.
- 알바 받기: 다른 사람이 옷걸이 클릭 (신청) → 점주가 발주 단말기를 웅크리고 클릭 (수락). 관리자: `알바 <가게> <허용|해제|목록> [플레이어]`.
- 관리자: `권리증 <플레이어> <골목점|표준점|대형점>` 지급, `내가게` 목록, `회수 <플레이어>` (허물고 권리증은 우편함).

## 5. 경력 (받은 손님 수, 평생)

수습 → **알바** (야간 근무 가능, 수습은 밤 20~06시 출근 거절) → **선임** (발주 · 스캔 2개) → **점장 대리** (폐기 할인 스티커: 폐기를 반값에 팔아 불평 없음 +40 G · 2인 근무 계산 담당) →
**점장** (칭호 `economy:store_manager` · 점장 조끼 · 스캔 3개). 가게마다 이번 달 가장 많이 받은 사람이 간판 아래 "이달의 점장 ○○".
`/관리자 편의점 경력 <플레이어> [단계]` 로 보기 · 맞추기.

## 6. 이벤트 · 손님

- **진상 12종** (`진상 <id>`): banmal 반말 · refund 환불 · credit 외상 (할머니가 가게에 있으면 그냥 냄) · steal 슬쩍 (주머니에 넣는 걸 보고 나가기 전에 바라보고 우클릭) · drunk 잠든 취객 ·
  kid 100원 모자람 · grandma 느린 할머니 · tourist 관광객 (진열대 가리키기) · exam 공시생 · parcel 택배 · lottery 복권 · ghost 새벽 문종 (분위기만).
- **신분증** (`신분증`): 술 · 담배 손님 → [신분증 확인] → 생년 보고 판매/거절. 형 신분증 (얼굴이 다름) 도 있음. 잘못 팔면 벌금, 괜히 거절하면 화냄. 직영점 · 대형점만.
- **단골 메뉴** (`단골 [종류]`): 같은 종류 5번 넘게 → 30% 확률로 "늘 먹던 걸로" → 맞는 진열대 · 냉장고 우클릭 (20초 뒤 귀띔) → 기분 +15 · 팁 ×2, 도감에 "단골 메뉴" 줄.
- **하루 이벤트** (60초마다 굴림, 가게마다 하루 하나): 정전 3% (`정전`, 차단기로 복구 · 카드 불가), 수학여행 3% (`단체`, 학생 8~12명), 본사 점검 2% (`점검`, 2분).
- **러시** (`러시`), **버스 질문** (`버스`, 정류장 24칸 안), **발주** (`발주 [rain|market|cold|night|snack]`).
- **장면** 70개 (`장면 [id]`, 출연 손님이 가게 안에 있어야): 버스와 같은 규칙 (12% · 10분 쉬기 · 안 본 것 ×4). 남녀 짝은 언제나 남+여.
- **날씨 · 달력**: 비 = 우산, 여름 = 아이스크림, 장날 = 손님 ×1.5.
- **버스 연동**: 가게 손님 50% 가 근처 정류장에서 산 물건을 들고 기다림 (정류장마다 최대 3),
  버스로 10번 넘게 태운 사람은 가게에서, 가게에서 10번 넘게 받은 사람은 버스에서 알아봄.

## 7. 혼자 시험하기 (순서)

1. `건설 시험점` → `시험` (돈 · 도감 · 기록 없는 근무, 다시 하면 끝).
2. `손님 grandma` → 스캔 · 계산 · 거스름돈 / `배송` → 상자 진열 / 데우기 손님 기다리기.
3. `진상 steal` · `진상 credit` · `신분증` · `폐기` · `청소` · `단골 student` · `버스`.
4. `경력 <나> 점장` → 다시 출근 (점장 조끼 · 3개 스캔), `러시` · `정전` (차단기) · `단체` · `점검` · `발주 rain`.
5. `권리증 <나> 대형점` → 내 땅에서 짓기 → 다른 계정으로 알바 신청 · 수락.
6. 숨은 비밀: `/관리자 비밀 테스트 켜기` 뒤 근무 → 30초 안에 새벽 손님 (`단계 새벽단골 <나> 4` = 마지막).

## 8. 알아 둘 것 · 남은 것

- **보이는 행동 (기획안 §17)**: 근무자가 하는 일은 손에 든 것 · 팔 휘두름 · 가구 모델 바뀜 · 물건 움직임으로 보이고 글자는 거의 없음.
  쓰는 모델 id 는 §17 표 그대로 (`store_held_*`, `store_microwave_open|run|done`, `store_kettle_low|empty`, `store_order_tablet_<묶음 상자>|sent`,
  `store_hanger_empty`, `store_spill_2|3`, `store_wet_sign`, `store_box_<종류>_open`, `store_id_card`). 팩에 아직 없는 모델은 **건너뜀**: 손에 쥐여 주지 않고
  예전처럼 짧은 글자로 알림 (대걸레가 없으면 한 번에 닦기, 쟁반이 없으면 컵이 바로 치워짐, 단계 모델이 없으면 첫 웅덩이를 작게 그림, 열린 상자가 없으면 닫힌 상자).
  - 손에 든 것은 스캐너 칸에 들어갔다가 스캐너로 돌아옴 · 버리기 · 옮기기 · 손 바꾸기 · 핫바 넘기기 불가 · 퇴근 / 접속 종료 / 죽음 / 접속 때 (근무 중 아니면) 사라짐.
    2인 근무: 상자는 든 사람만 채움, 대걸레는 한 사람만. 한 사람이 나가면 들던 상자는 창고 문 앞으로, 대걸레는 통으로.
  - 가구 모델 상태 (빈 옷걸이 · 전자레인지 · 온수기 물 · 단말기 화면 · 진열대) 는 서버 시작 · 청크 로드 · 출퇴근 때 지금 상태로 다시 맞춤 (서버가 꺼져도 남지 않음).
  - 잠깐 뜨는 표시 (튀어 오르는 물건 · 열린 상자 · 봉투 · 연기 속 음식) 는 모든 가게 합쳐 **40개까지**, 넘으면 그 연출만 건너뜀. 움직임은 클라이언트 보간 (매 틱 텔레포트 없음).
  - 발주한 묶음의 상자는 그 진열대가 가득이어도 다음 날 배송에 섞여 옴 (묶음 → 상자: 우산·따끈한 것 = 라면, 도시락·생활용품 = 도시락, 음료·아이스크림 = 음료, 술·안주 = 음료, 과자·간식 = 과자).
- 손님 머리 위의 이름표는 손님 종류 (버스와 같음) 뿐이고, 마네킹 기본 설명줄 "NPC" 는 지움 (손님 · 짝 · 점검원 · 새벽 손님 · 파라솔의 사람).

- 게임 안에서 아직 한 번도 안 돌려 봄. 위치 · 방향 · 크기 문제는 첫 건설에서 확인.
- 근무 · 재고 · 알바 신청 · 그날 발주 첫 보너스 표시는 저장 안 됨 (재시작하면 근무는 정산되고 재고는 다시 채워짐). 경력 · 내 가게 · 비밀 진행은 저장.
- **말풍선**: 손님마다 하나 (새 말이 앞 말을 바로 지움). 옆으로 2칸 안의 손님 말풍선 · 계산대 화면 · 초록 버튼과 겹치지 않게 한 줄 위로 비켜 뜨고,
  천장 (3칸) 아래 자리가 없으면 자리가 날 때까지 최대 3초 기다림 (구경 혼잣말 · 정전 · 수학여행 투덜은 자리 있을 때만). 장면 대사는 한 줄씩 (앞 말풍선을 내리고).
  높이는 말풍선이 머리 위 2.35칸에 뜬다는 어림으로 잡음 (`store/Bubbles.java`): 첫 근무 때 계산대 손님 말풍선이 화면 위 · 천장 아래에 오는지 눈으로 확인.
- 이번 버전에서 플레이어 손님 기능을 지우며 그 음식 아이템 (삼각김밥 · 컵라면 · 음료 등 23가지 + 뜨거운 컵라면 3) 도 지움: 예전에 산 것이 인벤토리에 있으면
  그대로 남음 (모양 · 먹기는 물건에 들어 있음; 더 생기지 않을 뿐, 물 붓기 전 컵라면은 이제 먹을 수 없음). 계산 안 한 "(계산 전)" 물건은 접속 · 접속 종료 때 저절로 사라짐.
  사탕 · 바나나우유 · 폐기 삼각김밥은 그대로.
- 진상 응대 버튼은 글자판 (그림 버튼 아님). 모든 등급이 같은 17×17 건물 (작은 등급은 가구만 빠짐). 명절 선물세트 없음. 플레이어용 `/편의점` 명령 없음 (옷걸이 · 단말기로).
- 데이터: 경력 `eco_store_career`, 내 가게 · 장면 본 기록은 경제 DB / `eco.kv`.
