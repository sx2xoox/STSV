# UI 문구 규칙 (플레이어에게 보이는 글)

**목표: 한 번에 읽히게.** 메뉴 칸 설명 · 채팅 · 제목 · 액션바 모두 같은 규칙. 코어 `messages.yml`, 경제 `messages.yml`, 메뉴 yml, 아이템 yml 공통.

## 길이
- **한 줄에 한 가지.** 아이콘 · 제목 · 이름이 이미 말하는 것은 다시 쓰지 않는다.
- **칸 설명(lore): 4줄 이내**, 한 줄은 한글 **24자 안팎**. 문장보다 **숫자 · 사실**("값 100 G", "보유 3/12").
- **채팅: 한 줄**이 기본. **결과를 먼저**("구매했습니다: 하이퍼카"), 덧붙일 것은 뒤에 흐린 색으로 짧게.
- 긴 사용법을 채팅에 늘어놓지 않는다: 명령어 하나나 메뉴를 가리킨다("/후원 에서").
- "~할 수 있습니다", "~입니다" 같은 설명체보다 짧은 끝맺음("~해요", 명사형). 같은 화면 안에서는 한 가지로.
- 제목(메뉴 이름): 짧게. 176px 패널 안에 들어가야 함(`MenuActionsTest` 가 잼).

## 쓰지 않는 것
- 내부 말: 설정 키(`config backup.min-free-gb`), 파일 이름, 엔티티 · 패킷 같은 개발 용어. (관리자 전용 문구는 예외로 둘 수 있지만 그래도 짧게)
- "이것은 ~입니다" 식 풀이, 같은 말 되풀이, 괄호 속 괄호.
- 한 줄에 색 여러 개(무지개).

## 클릭 안내 (칸 설명 맨 아래, 이 모양 그대로)
- `<yellow>클릭: ~` · `<yellow>우클릭: ~` · `<yellow>쉬프트 클릭: ~`
- 안내가 둘 이상이면 한 줄에 하나씩. 안내 위에 빈 줄 하나.

## 색
| 쓰임 | 색 |
|---|---|
| 본문 · 설명 | `<gray>` |
| 핵심 값 · 이름 | `<white>` |
| 돈 · 별(★) | `<gold>` |
| 좋음 · 완료 · 보유 | `<green>` |
| 안 됨 · 모자람 · 잠김 | `<red>` |
| 덧붙임(덜 중요) | `<dark_gray>` |
| 클릭 안내 · 주의 | `<yellow>` |

## 예
- 전: `<gray>스킨북을 들고 <white>우클릭</white> → 가운데 칸에 도구를 넣으면 스킨이 입혀집니다. · /스킨 해제 - 손에 든 도구의 스킨을 떼고 스킨북을 돌려받음`
- 후: `<gray>스킨북 우클릭 → 도구를 넣으면 스킨 적용 <dark_gray>· /스킨 해제: 떼고 책 돌려받기`
