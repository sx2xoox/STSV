# 편의점 알바 — 상세 기획안 (2026-11-26, 승인 전)

마을버스 다음의 "현실 일" 1호. 버스가 **움직이며 사람을 태우는 일**이라면 편의점은 **한자리에서 사람을 맞는 일**.
버스의 성공 요소 (역할 연기 · 성격 있는 손님 · 랜덤 장면 · 남이 같이 봄 · 숨은 비밀) 를 그대로 옮기고,
손님은 **버스와 같은 동네 사람들** (bus.yml types · people.yml 도감) 을 함께 쓴다.

원칙: 창(UI)이 아니라 **건물 안에서 손으로** 한다 (도박장과 같은 방침). 조작은 바라보고 누르기 (ButtonPick 조준 보정 재사용).

---

## 1. 한 줄 요약

카운터 뒤 조끼를 입으면 근무 시작 → 동네 사람들이 들어와 물건을 골라 카운터에 올림 → 바코드를 찍고 계산 →
틈틈이 진열 · 청소 · 진상 응대 → 퇴근하면 시급 + 팁 + 평점 보너스. 손님마다 성격 · 단골 메뉴 · 사연이 있고, 가끔 손님끼리 장면이 벌어진다.

## 2. 건물 (STSV24 편의점)

- `/관리자 편의점 건설 [이름]` : 선 자리 · 방향 기준 자동 건설 (HallBuilder 방식, 틱당 나눠 짓기). 여러 곳에 지을 수 있음 (마을점 · 항구점 …).
- 외관: 동네 골목 편의점. 통유리 전면, 초록/흰 간판 (불 들어옴), 문 위 딸랑 종, 바깥 파라솔 테이블 2개 · 쓰레기통 · 아이스크림 냉동고 · 뽑기 기계.
- 안 (약 11×9): 카운터 (계산대 · 담배 진열장 · 복권 통 · 전자레인지 · 온수기), 진열대 4줄 (과자 · 라면 · 생필품 · 도시락), 벽면 냉장 쇼케이스 (음료 · 유제품 · 술),
  뒤쪽 창고 문 (상자 쌓임), 시식대 (컵라면 먹는 자리 3석), 대걸레 · 폐기 바구니.
- 가구 · 모델 (economy 네임스페이스, assetgen `models/store.py` 한 파일로): `store_counter`, `store_shelf_<snack|noodle|daily|meal>`,
  `store_fridge`, `store_microwave`, `store_kettle`, `store_parasol`, `store_freezer`, `store_box` (배송 상자), 상품 모델 약 30종 (아래 4절), 버튼 · 스캐너 · 신분증 · 지폐/동전.
- 미리보기: `docs/previews/store*.png` (바깥 · 지붕 뗀 위).
- 편의점 앞에 버스 정류장을 두면 자동으로 "편의점 앞" 연동 (9절).

## 3. 근무 흐름

1. **출근**: 카운터 뒤 옷걸이의 조끼 우클릭 → 근무 시작 (조끼 스킨 겹쳐 입음 · 이름표). 한 점포에 근무자 1명 (2차에서 2명: 계산 + 진열).
2. **손님**: 문 종이 딸랑 → 들어와서 진열대를 돌며 고름 (손에 든 물건이 보임) → 카운터에 물건을 올려놓음 (1~5개, 실제로 놓임).
3. **계산**: 스캐너 (근무 중 손에 자동 지급, 버릴 수 없음) 로 물건을 하나씩 바라보고 우클릭 → "삑" + 계산대 화면에 금액이 쌓임.
   - 카드 손님 (약 60%): 손님이 카드를 내밂 → 단말기 우클릭 → 끝.
   - 현금 손님: 손님이 낸 돈이 카운터에 보임 → 거스름돈 버튼 (1000 · 500 · 100 …) 을 눌러 맞추고 [건네기]. 맞으면 보너스, 틀리면 손님 반응 (적게 주면 화냄, 많이 주면 내 시급에서 빠짐).
   - 봉투 필요? (손님이 말하면 봉투 버튼), 영수증 버려 주세요 등 한마디 응대.
4. **기다림**: 줄 선 손님은 참을성 게이지 (버스 patience 재사용). 빨리 · 정확히 = 기분 ↑ = 팁 · 평점.
5. **퇴근**: 조끼를 다시 걸면 정산 영수증 (손님 수 · 정확도 · 평점 · 시급 · 팁 · 특이사항 "오늘의 한마디"). 자리 비움 3분이면 자동 퇴근.

화면: 액션바 한 줄 (지금 손님 · 금액 · 줄 인원), 오른쪽 아래 보드 = 오늘 근무 (손님 수 · 평점 ★ · 매출 · 할 일 알림: "라면 진열대 비었음").

## 4. 상품 (약 30종)

삼각김밥 (참치마요 · 전주비빔 · 불고기) · 도시락 · 컵라면 (3종) · 핫바 · 구운 계란 · 바나나우유 · 커피 (캔 · 컵) · 탄산 · 이온음료 · 생수 ·
숙취해소제 · 과자 (3종) · 젤리 · 초콜릿 · 아이스크림 (2종) · 껌 · 우산 · 건전지 · 휴지 · 반창고 · 즉석복권 · 소주 · 맥주 · 담배 (진열장) · 교통카드 충전.

- 손님 종류마다 **잘 사는 것** 이 다름 (학생 = 삼각김밥 · 젤리, 회사원 = 커피 · 숙취해소제, 등산객 = 생수 · 초콜릿, 취객 = 숙취해소제 · 컵라면, 할머니 = 사탕 · 휴지 …).
- **단골 메뉴**: 그 손님을 5번 넘게 받으면 "늘 먹던 걸로" 라고만 말함 → 알아서 꺼내 주면 큰 호감 (도감에 단골 메뉴가 적힘).

## 5. 계산 말고 하는 일

| 일 | 내용 | 안 하면 |
|---|---|---|
| **진열** | 배송 트럭이 하루 두 번 (아침 · 저녁) 상자를 창고 앞에 내려놓음. 상자를 들고 맞는 진열대 우클릭 | 빈 칸의 물건을 찾던 손님이 그냥 나감 (평점 ↓) |
| **폐기** | 유통기한 지난 삼각김밥 · 도시락에 빨간 딱지 → 폐기 바구니로. **폐기는 근무자가 먹어도 됨** (알바의 낙) | 손님이 집으면 항의 |
| **데우기** | "데워 주세요" → 전자레인지에 넣고 20초 뒤 "띵" → 꺼내 줌. 잊으면 탐 | 손님 화냄 |
| **온수** | 컵라면 손님이 시식대에서 먹고 감. 온수기 물이 떨어지면 채움 | 손님 실망 |
| **청소** | 쏟은 음료 · 시식대에 남긴 컵라면 → 대걸레 · 치우기 | 다음 손님 기분 ↓ |
| **신분증** | 술 · 담배를 사는 어려 보이는 손님 → [신분증 확인] → 신분증에 적힌 해를 보고 판매 / 거절. 학생이 형 신분증을 들고 오기도 (사진이 다름) | 잘못 팔면 벌점, 괜히 거절하면 손님 화냄 |

## 6. 손님 (버스의 동네 사람들 그대로)

- bus.yml types 의 사람 · 스킨 · 별난 손님(shiny) 을 그대로 씀. 편의점 전용 대사 묶음만 `store.yml` 에 더함 (들어올 때 · 고를 때 · 계산 · 기다림 · 고맙다 · 화남).
- **인물 도감**: people.yml `places` 에 `store: 편의점` 도장 추가. 편의점에서 받은 것도 만난 횟수에 셈 (소개 글이 버스와 같이 열림).
- **서로 알아봄**: 버스로 10번 넘게 태운 사람은 "어, 기사님 아니세요?" / 편의점 단골을 버스에서 태우면 "알바생이 운전도 해요?".
- 시간대 (게임 시간): 아침 = 회사원 · 학생 러시, 낮 = 주민 · 할머니, 하교 = 학생 떼, 밤 = 취객 · 대리기사 · 커플, 새벽 = 드문드문 + 이상한 손님.
- 날씨 · 달력: 비 오면 우산이 동남, 여름 = 아이스크림, 장날 = 손님 ×1.5, 명절 전 = 선물세트.

**편의점만의 손님 행동** (1차 12종 → 2차에서 늘림)

| 종류 | 행동 | 좋은 응대 |
|---|---|---|
| 반말 아저씨 | "야, 담배." 종류를 안 말함 | 침착하게 [어떤 걸로 드릴까요] |
| 환불 손님 | 영수증 없이 먹다 남은 걸 환불해 달라 함 | [정중히 거절] (들어주면 내 돈) |
| 건달 | 외상 달아 달라 함 | [안 됩니다] 단호히 → 투덜대며 냄. 할머니가 같이 있으면 알아서 얌전 |
| 슬쩍 손님 | 고르는 척 주머니에 넣음 (눈여겨보면 보임) | 나가기 전에 바라보고 우클릭 → "…계산할게요" |
| 취객 | 시식대에서 잠듦 | 깨우기 / 숙취해소제 건네기 (팁) |
| 초등학생 | 동전을 세어 보다 100원 모자람 | [깎아 주기] (내 돈 100, 큰 호감 · 도감 줄) |
| 할머니 | 천천히 고르고 사탕을 하나 쥐여 줌 | 기다려 주기 |
| 외국인 관광객 | 손짓으로 물건을 찾음 | 맞는 진열대를 가리키기 |
| 공시생 | 삼각김밥 하나를 오래 고름, 폐기 시간에 맞춰 옴 | 폐기를 [몰래 하나 더] |
| 택배 맡기는 사람 | 상자를 맡김 (무게 재고 접수) | 접수 (택배 일과 이어질 자리) |
| 복권 손님 | 즉석복권을 그 자리에서 긁음 → 당첨이면 가게가 들썩 | 축하 |
| 유령 손님 (새벽) | 문 종만 울리고 아무도 없음 / 물건이 혼자 카운터에 | (숨은 비밀의 입구, 10절) |

응대는 손님 머리 위에 뜨는 버튼 2~3개 중 하나를 누르는 방식. 정답이 하나가 아니라 **성격에 따라 결과가 다름** (같은 건달도 기분 · 동행에 따라).

**손님끼리 장면**: 버스 합승 장면 엔진 (BusScenes) 을 장소 무관하게 넓혀 `store_scenes.yml` 로. 예: 마지막 도시락을 두고 학생과 회사원,
취객에게 물 건네는 할머니, 커플의 "아무거나" 싸움. 버스처럼 확률 · 쉬는 시간 · 안 본 장면 우선.

## 7. 진짜 플레이어 손님

- 근무자가 있으면 **다른 플레이어도 물건을 집어 카운터에 올려 살 수 있음** (친구 버스를 타 주는 것과 같은 재미). 상품은 실제 음식 아이템 (허기 회복, 컵라면은 온수 필요).
- 근무자가 없으면 **무인 계산대** (종류 적고 조금 비쌈) — 가게가 죽어 있지 않게.
- 상품 값은 서버로 사라지는 돈 (소모처). 근무자는 판매 건마다 소액 수당.

## 8. 보수 · 성장

- 보수 = **기본 (손님 한 명당)** + **팁 (기분)** + **정확도 보너스** + **퇴근 평점 보너스**. 목표: **버스와 비슷한 시간당 수입** (수치는 구현 때 bus.yml 실제 값에 맞춰 store.yml 에서 조절).
  손님 간격 기본 20~45초 (시간대 배수), 혼잡 시 줄 최대 5명.
- **경력** (근무한 손님 수로): 수습 → 알바 → 선임 → 점장 대리 → 점장.
  - 알바: 야간 근무 가능 (취객 · 새벽 손님, 시급 ×1.3)
  - 선임: **발주** (내일 들어올 물건을 고름. 날씨 · 달력을 읽고 맞히면 매출 보너스)
  - 점장 대리: 2인 근무의 선임 자리, 폐기 할인 스티커
  - 점장: 칭호 · 점포 간판 아래 "이달의 점장 ○○" · 전용 조끼
- 업적 · 칭호 · 스탬프 (기존 시스템): 첫 근무, 거스름돈 100번 연속 정확, 단골 10명, 진상 전 종류 응대 …

## 9. 버스와 잇기

- 편의점 앞 정류장에서 타는 손님은 방금 산 걸 들고 탐 (버스 hold 소품 재사용: 봉지 · 우산 · 아이스크림).
- 버스 기사가 근무 중에 캔커피를 사 마시면 잠깐 손님 졸음 깨움 효과 같은 작은 덕 (2차, 수치는 작게).
- 교통카드 충전 손님 → "다음 버스 언제 와요?" (근처에 운행 중인 버스가 있으면 실제로 알려 줄 수 있음: 기사 이름이 대사에).
- 같은 사람 · 같은 도감 · 서로 알아보는 대사 (6절).

## 10. 숨은 비밀 (3차, 관리자 문서에만)

"새벽 근무" 계열 하나. 야간 근무를 오래 한 사람에게만, 낮에는 절대 오지 않는 손님이 매번 같은 물건 하나를 사 감.
상세는 구현 때 `docs/admin/숨은_비밀/` 에만 적음 (플레이어용 안내 · README 에는 쓰지 않음).

## 11. 만드는 것 (기술)

- 모듈 `economy/.../store/` : `StoreModule` (점포 · 근무 · 정산), `StoreLayout` / `StoreBuilder` (건물), `Shopper` (손님 한 명의 상태 기계: 입장 → 고르기 → 줄 → 계산 → 퇴장,
  점포 안은 미리 정한 길목 그래프로만 걸음 = 길찾기 없음), `Checkout` (스캔 · 결제 · 거스름돈), `Chores` (진열 · 폐기 · 데우기 · 청소), `StoreScenes`.
- 내용 `content/economy/store.yml` (상품 · 값 · 손님별 취향 · 시간대 · 보수 · 대사), `store_scenes.yml`.
- 재사용: 버스 손님 표시 방식 · patience · mood · 대사 · 장면 엔진, ButtonPick, HudModule.board / 액션바, 인물 도감, 가구 (FurnitureModule), 건설 큐.
- 렌더 예산 안에서 (예산 올리지 않음): 점포 안 손님 동시 최대 6, 상품 표시는 진열대 모델에 구워 넣고 빈 칸만 상태 바꿈.
- 테스트: 거스름돈 · 정산 · 손님 상태 기계 · 취향 뽑기 · 내용 검증 (ContentTest) 단위 테스트.

## 12. 단계

| 단계 | 들어가는 것 | 결과 |
|---|---|---|
