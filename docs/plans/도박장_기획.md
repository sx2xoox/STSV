# 도박장 (화투방을 건물 안 실제 테이블로) — 기획 · 작업 계약 (2026-11-25)

주인 결정: 화투방은 UI 창이 아니라 **도박장 건물 안 테이블에 앉아서** 한다. 외관은 한옥이 아니라 **공사장 가설 사무소** 느낌.
"대충 만들지 말고 제대로." 판의 규칙(Table · Betting · Sutda · ChipStore · 자릿세 · 칩)은 그대로 쓰고, 노는 장소와 방법만 바꾼다.

## 1. 건물 (공사장 가설 사무소)

- `/관리자 도박장 건설` : 선 자리 · 바라보는 방향 기준으로 자동 건설. 하역장(DockBuilder · BlockBudget · ChunkQueue · LoadGate)처럼 틱당 나눠 짓기.
- 부지 둘레: 파란 공사 가림막(펜스) · 철골 비계 · 입구 "공사중 · 관계자 외 출입금지" 표지판 · 노랑/검정 줄무늬.
- 본관: 컨테이너 2~3동을 이어 붙인 1층 + 위에 얹은 1동(2층, 구경석 · 계단). 바깥: 시멘트 포대, 철근 더미, 안전 고깔, 공사 조명(삼각대), 드럼통 모닥불, 자재 팔레트.
- 안: 합판 바닥, 백열전구 · 형광등 섞어 약간 어둑하게, 담배연기 같은 파티클 약간. 현장 사무실 책상 = 칩 환전 창구(현장 소장 NPC), 화이트보드 = 오늘의 큰 판.
- 테이블 6개 (기본 배치): 섯다 초보방 · 섯다 일반방 · 섯다 큰손방 · 주사위 초보방 · 홀짝 초보방 · 홀짝 일반방. 테이블마다 위에 팻말(종목 · 방 · 판돈).
- 미리보기: dock_preview / tuning_shop_preview 처럼 레이아웃 JSON → `docs/previews/gamble_hall*.png` (바깥 · 지붕 뗀 위에서).

## 2. 아이템 · 모델 ID 계약 (모두 economy 네임스페이스)

가구 (core furniture, 좌석 포함):
- `economy:gamble_table_round` — 케이블 드럼 위 녹색 천(군데군데 담뱃불 자국 · 테이프 보수) + 둘레 의자 6개(플라스틱 의자 · 페인트 통 섞어서). 좌석 6. 섯다 · 주사위용.
- `economy:gamble_table_duel` — 작은 드럼(또는 각목 상자) 테이블 + 마주 보는 의자 2개. 좌석 2. 홀짝용.
- 좌석 번호(seat index)는 시계 방향, 0번이 테이블 정면(가구의 앞쪽). 게임 쪽은 좌석 번호 → 자리 번호로 그대로 씀.

표시 전용 아이템 모델 (ItemDisplay 로 띄움, 손에 들 아이템 아님):
- `economy:gamble_card_<월><a|b>` (예: gamble_card_1a … gamble_card_10b, 20장) · `economy:gamble_card_back` — 테이블 위에 눕혀 놓을 화투 패 (앞면 그림은 hwatu_icons 의 카드와 같은 디자인, 두께 있는 얇은 판).
- `economy:gamble_chips_1` … `gamble_chips_5` — 칩 더미 (높이 · 개수 5단계, 빨강/파랑/흰 칩 섞임).
- `economy:gamble_die` — 주사위 (면마다 눈, 1번 면이 위 · 기본 회전에서 각 면 방향 표를 README 에 적기).
- `economy:gamble_bowl` — 홀짝 사발 (엎어 놓은 상태가 기본).
- `economy:gamble_btn_<call|die|raise|odd|even|ready|leave>` — 내 차례에 자리 앞에 뜨는 버튼 (공사장 느낌: 노란 안전 표지판 · 스텐실 글씨).
- `economy:gamble_whiteboard` — 화이트보드 (글씨는 TextDisplay 로 따로 얹음).
- 건물 소품 (ItemDisplay 또는 가구): `economy:gamble_prop_cement` (시멘트 포대 더미), `gamble_prop_rebar` (철근 다발), `gamble_prop_cone` (안전 고깔), `gamble_prop_worklight` (삼각대 작업등), `gamble_prop_drumfire` (드럼통 모닥불), `gamble_prop_sign` ("공사중 · 관계자 외 출입금지" 표지판), `gamble_prop_pallet` (자재 팔레트).
- 현장 소장 스킨: 버스 손님 스킨과 같은 방식 (`economy:entity/bus/site_boss` 같은 키) — 노란 안전모, 형광 조끼, 배 나온 아저씨.

## 3. 게임 (테이블에서)

- 의자 우클릭 = 그 자리에 앉음 = 그 테이블의 판에 앉음 (칩 조건 · 판 도중 일어나면 다이 등 규칙은 Table 그대로).
- 테이블의 종목 · 방은 테이블에 저장. 건물이 지은 테이블은 기본 배치대로, 따로 놓은 테이블은 `/관리자 도박장 테이블 <종목> <방>` (보고 있는 테이블).
- 패: 테이블 위 자리 앞에 실제로 눕혀 놓음. **주인에게만 앞면**, 남에게는 뒷면 (플레이어별 숨김: 같은 자리에 앞면 · 뒷면 두 개를 띄우고 Player#hideEntity). 깔 때 모두 앞면.
- 칩: 가운데 더미가 판 크기에 따라 커짐. 주사위는 테이블 위에서 굴러가는 애니메이션, 홀짝은 사발을 들었다 내려놓음.
- 조작: 내 차례면 자리 앞 테이블 위에 버튼이 뜸 (나에게만 보이는 ItemDisplay + Interaction). 판돈 · 내 칩 · 남은 시간은 화면 오른쪽 아래 오버레이 (낚시대회판과 같은 HudLayout.Board).
- 구경: 누구나 볼 수 있음. 큰 판에서 이기면 건물 안에 효과 · 화이트보드에 기록.
- `/화투방` = 도박장으로 이동 (없으면 안내) · 칩 · 전적 창은 남김. 기존 로비 · 테이블 창은 없앰.
- 혼자 시험: `/관리자 도박장 시험` — 실제 테이블에서 봇과 (가짜 칩, 기록 안 남음). 섯다 패 정하기도 그대로.
